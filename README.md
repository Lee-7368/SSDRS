# SSDRS: 뇌졸중 정보 질의응답 챗봇 시스템

## 1. 프로젝트 개요

이 프로젝트는 **뇌졸중 관련 정보를 효율적으로 탐색하고 질의응답할 수 있도록 설계된 인공지능 챗봇 시스템**입니다. 사용자가 뇌졸중에 대한 질문을 입력하면, 시스템은 사전에 학습된 의료 문서를 기반으로 가장 관련성 높은 정보를 찾아 답변을 제공합니다. 이를 통해 의료 전문가가 아닌 일반 사용자도 뇌졸중 관련 정보를 쉽고 빠르게 얻을 수 있도록 돕습니다.

### 1.1. 문제 인식 및 개발 동기

세계보건기구(WHO) 자료에 따르면 뇌졸중은 여전히 높은 사망률을 보이는 심각한 질병입니다. 특히 베트남과 같은 국가에서는 뇌졸중으로 인한 사망률이 10만 명당 높은 수치를 기록하고 있습니다. 이러한 문제 인식 아래, **정확하고 신뢰할 수 있는 뇌졸중 정보를 신속하게 제공**하여 대중의 이해를 돕고, 필요한 경우 **적절한 의료 서비스로의 접근성을 높이는 것**을 목표로 본 시스템을 개발하게 되었습니다.

## 2. 주요 특징

*   **문서 기반 질의응답 (RAG: Retrieval Augmented Generation)**: 단순히 일반적인 지식으로 답변하는 것이 아니라, 프로젝트에 포함된 **뇌졸중 관련 공식 문서 및 가이드라인**을 참고하여 답변의 정확성과 신뢰성을 높였습니다. 이는 사용자가 의료 정보에 대한 신뢰를 가질 수 있도록 돕는 핵심 기능입니다.
*   **다양한 인공지능 모델 지원**: OpenAI의 GPT-4o, Anthropic의 Claude 3.5 Sonnet, Google의 Gemini 1.5 Pro 등 **다양한 최신 대규모 언어 모델(LLM)**을 선택적으로 활용하여 답변을 생성할 수 있습니다. 이를 통해 각 모델의 특장점을 활용하거나, 특정 모델에 대한 의존도를 줄여 유연한 시스템 운영이 가능합니다.
*   **직관적인 사용자 인터페이스**: **Streamlit**이라는 파이썬 웹 프레임워크를 사용하여 누구나 쉽게 접근하고 사용할 수 있는 웹 기반의 챗봇 인터페이스를 제공합니다. 별도의 설치 없이 웹 브라우저를 통해 접속하여 바로 이용할 수 있습니다.
*   **뇌졸중 전문 병원 찾기 기능**: 사용자의 현재 위치를 기반으로 **가까운 뇌졸중 치료 병원을 검색하고 지도에 표시**해주는 기능을 제공합니다. 이는 응급 상황 발생 시 신속한 의료기관 방문을 지원하여 골든타임 확보에 기여할 수 있습니다. 검색 반경은 최대 100km까지 조절 가능합니다.
*   **확장 가능한 지식 기반**: 새로운 뇌졸중 관련 문서나 가이드라인이 추가될 경우, 시스템에 쉽게 통합하여 챗봇의 지식 기반을 확장할 수 있습니다.

## 3. 구동 방법

이 프로젝트는 파이썬 기반으로 개발되었으며, 몇 가지 간단한 단계를 통해 실행할 수 있습니다.

### 3.1. 필수 요구사항

*   **Python 3.9 이상**: 파이썬이 설치되어 있지 않다면, [파이썬 공식 웹사이트](https://www.python.org/downloads/)에서 다운로드하여 설치해 주세요.
*   **pip**: 파이썬 패키지 관리 도구로, 일반적으로 파이썬 설치 시 함께 설치됩니다.

### 3.2. 환경 설정

프로젝트는 OpenAI, Anthropic, Google의 LLM API를 사용하므로, 해당 서비스의 API 키가 필요합니다. `.env` 파일을 생성하여 다음과 같이 API 키를 설정해야 합니다.

1.  프로젝트의 루트 디렉토리(`SSDRS-master`)에 `.env` 파일을 생성합니다.
2.  생성한 `.env` 파일에 다음 내용을 추가하고, `YOUR_API_KEY` 부분을 실제 API 키로 대체합니다.

    ```
    OPENAI_API_KEY=YOUR_OPENAI_API_KEY
    ANTHROPIC_API_KEY=YOUR_ANTHROPIC_API_KEY
    GOOGLE_API_KEY=YOUR_GOOGLE_API_KEY
    ```

    *   **참고**: 사용하고자 하는 LLM에 해당하는 API 키만 설정해도 무방합니다. 예를 들어, GPT 기반 챗봇만 사용하려면 `OPENAI_API_KEY`만 설정하면 됩니다.

### 3.3. 의존성 설치

프로젝트 실행에 필요한 라이브러리들을 설치합니다. 프로젝트 루트 디렉토리에서 다음 명령어를 실행합니다.

```bash
pip install -r requirements.txt
```

### 3.4. 애플리케이션 실행

모든 설정이 완료되면, 다음 명령어를 통해 챗봇 애플리케이션을 실행할 수 있습니다.

```bash
streamlit run rag_ui_main.py
```

명령어 실행 후 웹 브라우저가 자동으로 열리거나, 터미널에 표시되는 URL(`http://localhost:8501` 등)로 접속하면 챗봇 인터페이스를 확인할 수 있습니다.

## 4. 프로젝트 구조 (주요 파일)

*   `rag_ui_main.py`: 챗봇 시스템의 메인 페이지를 구성하고, 각 LLM 기반 챗봇 페이지로의 링크를 제공합니다.
*   `pages/GPT_BASED_RAG.py`: OpenAI의 GPT 모델을 활용한 뇌졸중 질의응답 챗봇 페이지입니다.
*   `pages/Claude_BASED_RAG.py`: Anthropic의 Claude 모델을 활용한 뇌졸중 질의응답 챗봇 페이지입니다.
*   `pages/Gemini_Based_RAG.py`: Google의 Gemini 모델을 활용한 뇌졸중 질의응답 챗봇 페이지입니다.
*   `pages/maps.py`: 뇌졸중 전문 병원 찾기 기능을 구현한 파일입니다.
*   `requirements.txt`: 프로젝트 실행에 필요한 파이썬 라이브러리 목록입니다.
*   `.cache/files/`: 챗봇의 지식 기반으로 사용되는 뇌졸중 관련 문서(PDF)들이 저장된 디렉토리입니다.

## 6. 향후 계획

본 프로젝트는 지속적인 발전을 목표로 합니다. 향후 다음과 같은 개선 및 확장 계획을 가지고 있습니다:

*   **다양한 LLM 추가**: Gemini와 같은 추가적인 LLM 모델을 통합하여 사용자에게 더 넓은 선택지를 제공하고, 각 모델의 장점을 활용할 예정입니다.
*   **사용자 피드백 반영**: 실제 사용자들의 피드백을 적극적으로 수렴하여 시스템의 편의성과 기능성을 개선할 것입니다.
*   **서비스 확장**: 뇌졸중 외에 다른 질병에 대한 정보 제공 및 진단 지원 기능으로 서비스를 확장하여, 더 많은 사람들에게 도움을 줄 수 있는 범용적인 의료 정보 플랫폼으로 발전시킬 계획입니다.
*   **프로그램 공개**: 개발된 프로그램을 웹 기반으로 공개하여 더 많은 사용자들이 쉽게 접근하고 활용할 수 있도록 할 예정입니다.
